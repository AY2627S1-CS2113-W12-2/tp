# Yan Hern — Project Portfolio Page

## Overview

TutorLedger is a Java command-line application for independent tutors teaching primary-school,
secondary-school and junior-college students. It keeps student profiles, lessons, homework, scores and
payment records together in a local data file.

My contributions focus on maintaining the student book, reducing repeated data entry and protecting
lesson history when a tutor changes or removes a student profile.

### Enhancements implemented

* **Student book** ([PR #60](https://github.com/AY2627S1-CS2113-W12-2/tp/pull/60)):
  implemented student commands and profile validation, including adding, finding, viewing, editing and
  deleting students. Student IDs link profiles to lesson and homework records so tutors can review a
  student's information together.
* **Default hourly rates and lesson duration**
  ([PR #81](https://github.com/AY2627S1-CS2113-W12-2/tp/pull/81)):
  added optional per-student rates and duration-aware scheduling with decimal rounding and explicit fee
  overrides. Existing lesson charges remain fixed when rates or durations change. The enhancement
  covers immutable profile copies, recurring schedules and backward-compatible storage metadata.
* **Primary and junior-college students**
  ([PR #84](https://github.com/AY2627S1-CS2113-W12-2/tp/pull/84)):
  extended level validation to Pri 1–6, Sec 1–5 and JC 1–2. Input is normalised consistently across
  commands and loading; changing school stage preserves the student's identity, rate and history.
* **Deletion warnings** ([PR #85](https://github.com/AY2627S1-CS2113-W12-2/tp/pull/85)):
  added a warning with linked-record counts before deleting a student with lessons. An explicit
  confirmation command prevents accidental cascading deletion without introducing a pending prompt.
* **Student archiving** ([PR #87](https://github.com/AY2627S1-CS2113-W12-2/tp/pull/87)):
  added archive/restore commands, active-list filtering and persistent archive state. History and
  balances remain accessible; new scheduling requires restoration. Profile edits and saved-file reloads
  preserve archive state, while student-count messages distinguish active and archived profiles.

### Enhancement awaiting merge

* **Covered topics** ([issue #18](https://github.com/AY2627S1-CS2113-W12-2/tp/issues/18)):
  implemented in the `covered-topics` branch for v2.0b. The read-only `topics` command lists notes from attended
  lessons, with historical subject filtering. Reusing lesson records avoids duplicate topic storage;
  corrections appear immediately. This enhancement is not yet merged upstream.
